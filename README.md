# Questify – Task Management Application

Questify is a React-based task management application designed to help users organize tasks, manage priorities, track deadlines, and monitor productivity through a simple dashboard.

## Features

- Create, edit, and delete tasks.
- Mark tasks as completed or pending.
- Set task priorities: High, Medium, and Low.
- Organize tasks by categories.
- Set due dates and track overdue tasks.
- Search tasks by title.
- Filter tasks by status and category.
- Sort tasks by priority, due date, and creation date.
- View task statistics and completion progress.
- Save tasks using browser localStorage.

## Tech Stack

- React.js
- JavaScript (ES6+)
- CSS3
- HTML5
- Vite
- Browser localStorage

## Installation and Setup

1. Clone the repository:

   `git clone https://github.com/MANOS-19/Questify-task-manager.git`

2. Navigate to the client folder:

   `cd Questify-task-manager/client`

3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the local URL displayed in your terminal.
